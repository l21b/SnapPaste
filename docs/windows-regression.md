# Windows 实机回归清单

每个发布候选版本至少在 Windows 11 上完整执行一次。建议同时保留一台不同缩放比例或 Windows 10 环境进行抽查。

## 启动与窗口

- [ ] 首次启动后主窗口保持隐藏，托盘图标可见。
- [ ] 按 `Alt+Z` 能在鼠标附近显示主窗口。
- [ ] 再次触发、点击窗口外部和按 Esc 时，窗口行为符合预期。
- [ ] 托盘菜单仅包含“设置”“关于”和“退出”，左键点击托盘图标仍可呼出主窗口。
- [ ] 连续快速触发快捷键 10 次，无崩溃、卡死或重复窗口。
- [ ] 100%、125%、150% 缩放下窗口完整显示且不会跑出屏幕。
- [ ] 双显示器之间移动鼠标后呼出，窗口出现在当前显示器可视区域。

## 剪贴板与粘贴

- [ ] 从记事本、浏览器、Office 和终端复制文本后均能生成记录。
- [ ] 重复复制相同内容只保留一条，并刷新到正确位置。
- [ ] 点击记录后能粘贴回原目标窗口，主窗口自动隐藏。
- [ ] 从快捷键和托盘分别呼出后，点击记录都能恢复原目标窗口并粘贴。
- [ ] 在浏览器、Office、Electron 应用的输入框内呼出，粘贴后光标仍位于原输入框。
- [ ] 管理员权限窗口无法接收模拟输入时，剪贴板内容仍可手动粘贴且不会误发到其他窗口。
- [ ] 快速连续复制 20 条内容无丢失、重复风暴或界面卡顿。
- [ ] 收藏、取消收藏、置顶、取消置顶和删除均立即生效。
- [ ] 搜索包含 `%`、`_`、反斜杠和中文时结果正确。
- [ ] 清空历史不会删除收藏；清空收藏只删除收藏内容。

## 设置与数据

- [ ] 设置页不显示实验性 AI 功能。
- [ ] 修改主快捷键后旧快捷键失效、新快捷键生效。
- [ ] 使用已被占用的快捷键时显示明确错误，原快捷键仍可使用。
- [ ] 主题、保留天数、最大记录数和开机启动保存后生效。
- [ ] 导出文件不包含 AI API Key。
- [ ] 导入收藏能够增量合并、保留置顶并刷新界面。
- [ ] 取消文件选择不会显示错误或关闭应用。

## 安装与恢复

- [ ] NSIS 全新安装、启动和卸载正常。
- [ ] 覆盖安装上一版本后，历史记录和设置仍然存在。
- [ ] 开机启动启用后重启 Windows，应用只启动一个实例。
- [ ] 强制结束进程后重新启动，数据库仍可读取且无损坏提示。
- [ ] 便携版和安装版不会同时造成多个后台实例。

## 界面独立预览

`cargo run -- --preview` 使用固定演示记录，不启动数据库、剪贴板监听、快捷键或开机启动同步。
添加 `--dark` 检查深色主题，添加 `--settings` 或 `--about` 直接检查对应弹窗。
添加 `--snapshot target/preview.png` 可保存 Slint 渲染的 PNG 后退出，便于自动对照布局。
预览中的数据操作不落盘；实际粘贴和快捷键焦点切换仍需按上面的实机清单验证。

- [ ] 浅色、深色下背景保持半透明，置顶为蓝色，收藏为橙色。
- [ ] 长文本自动换行，显式换行保留，下一条记录不重叠。
- [ ] 设置弹窗居中，正文可滚动，取消和保存固定在底部。
- [ ] 主题与快捷键下拉菜单跟随应用配色。
- [ ] 快捷键呼出后直接点击记录仍能粘贴；点击搜索可输入，添加、清空按钮可打开弹窗。

## 隐藏后重绘回归

- [ ] 呼出后输入 `ss`，关闭再呼出，标题、搜索栏和列表/空状态全部显示，搜索清空并恢复当前页面的完整列表。
- [ ] 分别通过 Esc、快捷键、点击外部隐藏，再从快捷键和托盘呼出，连续重复至少三次。
- [ ] 100%、125%、150% DPI 下重复以上操作，确认没有透明空洞或只显示搜索框。

自动回归在 `ui_interaction_tests.rs` 中模拟隐藏时丢失显示缓冲区、但保留渲染缓存的情形。
Windows 软件后端在每次实际绘制时使用完整帧，不再依赖单次显示时的区域失效。
Slint/slint-build 固定为 1.17.1，局部补丁及取舍见 `vendor/i-slint-backend-winit/SNAPPASTE-PATCH.md`。

## 原生拖动后点击回归

- [ ] 拖动标题栏松开后，第一次点击收藏、添加、搜索均正常。
- [ ] 拖动后隐藏，再从快捷键和托盘呼出，第一次点击正常，连续重复三次。
- [ ] 点击顶栏按钮不会进入原生拖动。

自动交互测试模拟原生拖动吞掉鼠标释放事件，分别检查原地继续点击和隐藏后重新呼出的点击。
原生拖动延迟到当前指针按下事件分发完成后执行；交接前后及重新显示时使用 PointerExited 取消 Slint 的鼠标捕获，不伪造点击。

- [ ] 连续呼出/隐藏至少 20 次，鼠标分别位于屏幕中央、四角和不同 DPI 显示器，首帧完整。
- [ ] 呼出后移动窗口、悬停按钮、输入搜索及等待光标闪烁，都不会出现局部残片。
- [ ] 软件缓冲区在首帧之后丢失时，后续小范围变化仍恢复整个画面（自动像素回归覆盖）。

## 即时呼出与失焦隐藏

- [ ] 呼出后立即点击其他应用即隐藏，无 500ms 保护期；停留后点击外部也无轮询等待。
- [ ] 连续开关 10 次，刚呼出的窗口不会被过期失焦事件误关。
- [ ] 搜索框可直接输入，拖动结束后点击外部立即隐藏。
- [ ] 设置、关于和设置内的下拉菜单/文件选择器仍可正常使用。

关闭使用 winit Focused(false) 事件，不再每 150ms 查询前台窗口。Windows 额外校验当前前台窗口，忽略旧事件和自有弹窗。
呼出直接显示已由剪贴板监听、搜索和数据操作维护的列表，不在快捷键回调内重复查询和解码。

## 记录操作按钮悬停

- [ ] 从记录正文移入置顶、删除、收藏按钮，按钮不闪烁或消失，点击只执行对应操作。
- [ ] 从搜索框直接进入按钮，再横向切换三个按钮，均可首次点击。

自动交互测试覆盖多次悬停重绘、直接进入及相邻按钮切换，并校验不会误触记录粘贴。

## 与旧版一致的按钮动效

- [ ] 顶栏添加蓝色、收藏橙色、删除红色；悬停上浮 1px，按下缩至 96%，200ms ease。
- [ ] 行内按钮 160ms 淡入，悬停上浮 1px 并放大至 105%，按下缩至 95%。
- [ ] 鼠标停在按钮边缘、动画期间反复点击时，操作仍稳定且不会触发记录粘贴。
- [ ] 浅色和深色下分隔线左右留白，空状态图标和弹窗清晰可读。

动效只改变内层绘制尺寸与位置，外层命中区域固定；不参与窗口显示或隐藏时序。

## 文字首列裁切

- [ ] 设置页的快捷键、主题、数字和说明文字左侧笔画完整，100%、125%、150% 缩放均检查。

`tests/text_clipping.rs` 对比整数/小数坐标的同一段文字像素，防止首字裁切。渲染器补丁位于 `vendor/i-slint-renderer-software`，将字形原点与裁切矩形统一取整。

## 原生画面提交

`cargo test --test windows_present -- --ignored` 需在已解锁桌面显式运行：创建专用测试窗口，反复部分移出屏幕、隐藏、移回和显示 20 次，并读取四角及中心像素验证完整提交。窗口自动销毁，不修改用户记录。

生产窗口使用 WS_EX_LAYERED + UpdateLayeredWindow，提交完整的预乘透明度 DIB；显示后额外请求一帧，避免隐藏状态的预渲染成为唯一提交。窗口样式未变时不重复执行 SWP_FRAMECHANGED。

原生测试创建相同的分层窗口，等待 DwmFlush 后从系统合成结果检查四角，并用测试自己的白色背景窗口检查中央透明像素。20 次循环中还会模拟窗口库重置分层样式，确认下一帧恢复完整提交。

非分层窗口仍使用 BitBlt，但每次提交获取/释放目标 DC，避免复用旧可见区域；提交失败会返回错误。此路径不是 SnapPaste 主窗口的提交方式。

- [ ] 任务管理器显示名称为 SnapPaste；构建产物的 FileDescription 和 ProductName 均为 SnapPaste。
