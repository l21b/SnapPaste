# Windows 实机回归清单

每个发布候选版本至少在 Windows 11 上完整执行一次。建议同时保留一台不同缩放比例或 Windows 10 环境进行抽查。

## 启动与窗口

- [ ] 首次启动后主窗口保持隐藏，托盘图标可见。
- [ ] 按 `Alt+Z` 能在鼠标附近显示主窗口。
- [ ] 再次触发、点击窗口外部和按 Esc 时，窗口行为符合预期。
- [ ] 托盘的“打开 SnapPaste”“设置”“关于”和“退出”均可使用。
- [ ] 连续快速触发快捷键 10 次，无崩溃、卡死或重复窗口。
- [ ] 100%、125%、150% 缩放下窗口完整显示且不会跑出屏幕。
- [ ] 双显示器之间移动鼠标后呼出，窗口出现在当前显示器可视区域。

## 剪贴板与粘贴

- [ ] 从记事本、浏览器、Office 和终端复制文本后均能生成记录。
- [ ] 重复复制相同内容只保留一条，并刷新到正确位置。
- [ ] 点击记录后能粘贴回原目标窗口，主窗口自动隐藏。
- [ ] 从快捷键和托盘分别呼出后，点击记录都能恢复原目标窗口并粘贴。
- [ ] 在浏览器、Office、Electron 应用的输入框内呼出，粘贴后光标仍位于原输入框。
- [ ] 管理员权限窗口无法接收模拟输入时，剪贴板内容仍可手动粘贴且不会误发到其他窗口。
- [ ] 快速连续复制 20 条内容无丢失、重复风暴或界面卡顿。
- [ ] 收藏、取消收藏、置顶、取消置顶和删除均立即生效。
- [ ] 搜索包含 `%`、`_`、反斜杠和中文时结果正确。
- [ ] 清空历史不会删除收藏；清空收藏只删除收藏内容。

## 设置与数据

- [ ] 设置页不显示实验性 AI 功能。
- [ ] 修改主快捷键后旧快捷键失效、新快捷键生效。
- [ ] 使用已被占用的快捷键时显示明确错误，原快捷键仍可使用。
- [ ] 主题、保留天数、最大记录数和开机启动保存后生效。
- [ ] 导出文件不包含 AI API Key。
- [ ] 导入收藏能够增量合并、保留置顶并刷新界面。
- [ ] 取消文件选择不会显示错误或关闭应用。

## 安装与恢复

- [ ] NSIS 全新安装、启动和卸载正常。
- [ ] 覆盖安装上一版本后，历史记录和设置仍然存在。
- [ ] 开机启动启用后重启 Windows，应用只启动一个实例。
- [ ] 强制结束进程后重新启动，数据库仍可读取且无损坏提示。
- [ ] 便携版和安装版不会同时造成多个后台实例。
