# SnapPaste 1.6.1

本次更新集中修复 Windows 窗口显示与交互问题，并统一界面样式。

## 修复

- 修复反复呼出、隐藏或移动窗口后，界面偶尔只显示局部残片的问题。
- 修复拖动窗口后按钮无法点击、首次点击下拉框无响应的问题。
- 修复设置页文字左侧笔画被裁切的问题。
- 修复记录操作按钮悬停时消失、底色丢失的问题。
- 关闭后再次呼出时清空搜索，恢复当前页面的完整列表。
- 改进失焦隐藏响应，移除轮询与延迟保护期。
- 将 Windows 任务管理器使用的程序描述统一为 SnapPaste。

## 界面与文档

- 统一浅色、深色界面的背景、按钮颜色和悬停动画。
- 置顶和收藏选中时显示实心图标。
- 重新设计关于页面，添加 GitHub 图标入口。
- 精简托盘菜单，仅保留设置、关于和退出。
- 移除多余提示，新增中文版项目介绍及语言切换入口。

## 下载

- `SnapPaste-1.6.1-setup.exe`：Windows 安装版。
- `SnapPaste-1.6.1-windows-x64-portable.zip`：Windows x64 便携版。
- `SHA256SUMS.txt`：下载文件校验值。

当前版本以文本剪贴板功能为主，暂未开放图片记录与图片粘贴功能。
